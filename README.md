# \# 🍞 우리는 '만나'예요! - 전도 \& 중보기도팀

# 

# > \*\*"매일 매일 내려오는 특별한 선물, 만나! 당신의 오늘이 더 달콤해지도록 우리가 함께 기도하고 전할게요."\*\* 💛

# 

# 리즈 청년부에서 전도와 중보기도를 맡고 있는 \*\*만나(Manna) 팀\*\*의 공식 웹사이트 저장소입니다. 

# 

# \---

# 

# \## ✨ 주요 기능

# \* \*\*📸 우리의 추억 (Gallery):\*\* 복음 배달, 간절한 중보기도, 즐거운 교제 등 만나팀의 사랑 가득한 순간들을 슬라이드로 확인합니다.

# \* \*\*⛅ 만나 담벼락 (Message Wall):\*\* 방문자들이 실시간으로 따뜻한 응원의 한마디를 남길 수 있는 실시간 포스트잇 담벼락입니다.

# \* \*\*💌 기도 요청 (Prayer Request):\*\* 기도가 필요한 청년들이 마음을 남기면 만나 팀이 함께 기도해 드립니다.

# \* \*\*🎯 오늘의 만나 말씀 뽑기:\*\* 오늘 나에게 주시는 달콤한 약속의 말씀을 무작위로 뽑아볼 수 있습니다.

# \* \*\*🎮 깜짝 퀴즈:\*\* 만나 팀에 대한 재미있는 초성 퀴즈가 준비되어 있습니다.

# 

# \---

#
